# 🌍 Travel Image Gallery

A responsive and interactive Travel Image Gallery built using HTML, CSS, and JavaScript. This project showcases beautiful travel destinations through an engaging gallery interface with filtering and lightbox functionality.

## 📌 Overview

The Travel Image Gallery provides users with an immersive browsing experience by allowing them to explore various destinations around the world. The project focuses on responsive design, smooth animations, and interactive user experiences.

## ✨ Features

* Display of multiple travel destination images
* Category-based image filtering
* Interactive lightbox view
* Next and Previous image navigation
* Keyboard navigation support
* Smooth hover effects and transitions
* Animated background effects
* Mobile-friendly responsive layout
* Clean and modern user interface

## 🎨 User Experience

The gallery is designed to provide a visually appealing experience with:

* Responsive image grid layout
* Elegant hover animations
* Smooth image transitions
* Interactive lightbox modal
* Easy category-based navigation
* Consistent design across devices

## 🛠️ Technologies Used
